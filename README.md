# Lullabies

![Django 4.2](https://img.shields.io/badge/django-4.2-092E20?logo=django&logoColor=white)

## Overview

**Kolyskova** is a web platform for **young parents and caregivers** that provides access to a collection of **calming lullabies and stories** for babies in **Ukrainian**.  
It is designed to offer a **peaceful**, **ad-free**, and **minimalistic experience** to help babies **fall asleep more easily**.

This repository contains the **backend code** powering the [Kolyskova website](https://www.kolyskova.com).
